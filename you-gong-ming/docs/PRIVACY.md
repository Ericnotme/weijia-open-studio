# 原型数据说明

当前网页的自由介绍、结构化选项和反馈只保存在 JavaScript 页面内存。刷新、关闭页面或点击“重新开始”会清除当前输入；“重新开始”随后展示虚构默认示例。

应用没有向服务器发送介绍的代码，没有数据库、浏览器持久化存储、广告、第三方分析或远程字体。托管服务自身的登录、访问日志及安全处理应以其政策为准。

复制功能会将选择导出的文案放入设备剪贴板。下载功能只生成本地文件。导出的自我介绍使用已确认的结构化选项，不自动复制自由介绍原文。日历文件标记为暂定，无参与者字段，不会向任何人发邀请。

如果当前浏览器支持 WebMCP，页面允许代理通过注册的工具读取或修改当前页面数据。实际代理调用需要遵循该浏览器和代理的权限规则；不需要此能力的发布方可以移除 app.js 中对应的注册段。

本说明仅适用于 v0.1 原型。将来接入模型、账号、匹配和消息服务前，必须重新设计和披露实际数据流，并取得用户对具体数据用途的同意。
