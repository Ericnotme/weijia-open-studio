# 人生原野 · Life Meadow

0—18岁育儿卡牌策略游戏，版本0.3。原创网页试玩，可作为未来Steam/微信小游戏的规则原型。

## 0.3 · PC试玩候选

保留0.2的规则与version:2存档格式，集中解决上手与复玩理解：顶部三步指南、显式卡牌负荷和基础成长、选牌前的收支拆分、选牌后的五维实际变化、约定预期进度、不可执行安排的具体原因、同种子同难度的本地结局对照、重绘焦点与隐藏导入控件修复。

纸样下载位于页脚：A4八页、六回合精简改编、24张可裁切组件及成长记录板。它不共用网页数值平衡；完整可复现样例结算为40星光、83最终成绩。

离线交付为独立HTML（内嵌本项目插画、CSS、规则及UI）和PDF的ZIP，无安装程序、第三方运行时或安全权限调整。离线版不加载联网反馈统计脚本，配乐与支持外链需要联网。线上与file://存档通过JSON导出导入转移。

验证：headless Chromium在独立配置中，通过两条18年完整UI策略复玩；原13项引擎测试通过，含100种子、各阶段存档往返、旧档迁移。存档版本保持2，不删除现有收藏。没有真人试玩、留存或市场验证；没有Steam账户、商店或平台接入。

## 0.2 · 连锁与约定

上一版的核心问题：每年的操作大多是加属性，事件缺少后续，最终目标离当下太远。这版增加了可观察的策略差异：

- **出牌顺序与流派**：探索→创造→社交可形成两段连锁；三种家庭节奏分别强化一条连接。手牌包含对应流派的两种类型和一张免费可用牌。
- **六个三年挑战**：篇章偏好、时间压缩、免费换牌、负荷要求和多样性要求会变化。累计星光达到目标的1/1.3/1.65倍获得1/2/3星；每星奖励2资金，不达标仍可继续。
- **两年的约定**：0/6/12岁各有两条故事路线。随后两年按活动类型累计进度，成功后选择专属牌或6资金。六张专属牌改变后续手牌。
- **规划下一手**：可花2资金把一张手牌留给下一年；选择可取消或改动，结算时只收费一次。专属牌与留牌冲突时优先专属牌并返还费用。
- **卡牌升级与信物构筑**：累计使用3/6次升至Lv.2/3，每级提高卡牌正向基础成长1点、基础星光3点。六件类型信物增加对应牌基础星光，万花筒强化三类型连锁。
- **旧存档迁移**：保留年龄、属性、历史和信物，补入当前篇章的基准进度，重新安排当前手牌。浏览器升级前保留原始v1备份；新局可体验完整故事。旧存档已过去的年份不伪造星光或约定成绩。

星光表示本局卡牌策略成绩，不代表孩子的价值。当前只是首轮平衡，未声称提高了真人留存。

## 运行

不需要构建，不依赖第三方运行时包。使用任意静态服务器将 `dist/` 作为站点根目录，例如：

```sh
python3 -m http.server 8080 --directory dist
```

浏览器打开 `http://localhost:8080`。不能直接用file://打开，因为使用ES Modules。

```sh
npm test
```

13项内置测试覆盖100个种子的完整18年对局、三种流派、所有阶段存档往返、确定性、非法操作、零资金事件路径、结算预览、顺序连锁、留牌计费、约定结果、升级与旧存档迁移。

## 结构

- `dist/engine.js`：不依赖DOM、网络或存储的规则引擎。
- `dist/data.js`：卡牌、社区、事件、信物与目标内容。
- `dist/play-content.js`：流派、连锁、篇章、跨年约定和专属牌。
- `dist/app.js`：界面和浏览器适配器、本地存档、分享摘要。
- `dist/style.css`：响应式样式。
- `dist/neighborhood.webp`：为本项目生成的原创插画。
- `tests/engine.test.mjs`：Node内置测试，无外部依赖。

游戏的五个状态是plan → event → plan/draft/end。新年只有在事件选择后开始，3/6/9/12/15岁进入信物三选一，18岁结束。

## 参数与科学边界

所有社区、收入、住房、教育指数和成长/健康系数均为虚构平衡参数。六座真实城市名只是故事背景，当前共用四类虚构社区。背景人口经济指数不直接作为成长加成。这里不是原机会地图的数据迁移，也不是真实育儿、疾病或购房预测工具。

每项年度成长＝round(正向基础收益 × (1 − 当前值/150) − 1)，负向值不乘缩减系数。基础收益含牌、社区、气质、组合和信物；压力超过55时计入活力与幸福惩罚。事件效果在年度结算后直接加入。所有状态范围0—100。

精神健康事件只讲支持与专业评估，不计算精神分裂症患病概率，不做诊断，不将健康事件等同人生失败。
