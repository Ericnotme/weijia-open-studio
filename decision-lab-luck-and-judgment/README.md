# 你赚了钱，但你真的做对了吗？

中文独立试玩版 v1.0，5 个虚构决策情景，建议留出约 15 分钟阅读和反思。没有时限、真实交易、账号、在线大模型或第三方追踪代码。

## 本地试玩

需要 Node.js 20 或更高版本；游戏和核心测试没有第三方依赖，不需要 `npm install`。

```sh
cd decision-lab-luck-and-judgment
npm start
```

浏览器打开 `http://127.0.0.1:4173`。用 `PORT=4174 npm start` 更换端口。服务器仅监听本机；公开手机试玩请使用交付的独立 Sites 链接。

## 玩法

1. 初始虚构现金 ¥20,000，其中 ¥10,000 是未来房租和生活费保护金。
2. 每轮可免费调查，选择等待或投入 ¥1,000 / ¥2,000 / ¥3,000；受剩余资金与损失预算限制。
3. 先选择理由和对决策过程的主观把握，可以补充笔记及观点更新方式，再锁定决定。
4. 揭晓一条种子固定的模拟结果，展示同一选择的五条随机路径与全部模型分支。
5. 完成五关后逐关回放，可下载 JSON 复盘，或以相同/不同实验编号重玩。

“过程把握”不是盈利概率。无总分、投资智商、能力标签、财富榜、交易次数奖励或连续操作奖励。等待有同样完整的过程反馈。反馈仅基于本情景的约束、调查记录、选中的理由和自述更新，不做自由文本语义推断；盈利不会提高评价。

## 可检验规则

- 所有金额用整数分计量，分支回报用整数基点计算，四舍五入到分；零统一为正零。
- 每轮头寸在当轮结算，无跨轮持仓。现金回报为零。
- 初始保护金 ¥10,000：第 2、4 轮各支付房租 ¥3,000，第 5 轮支付生活费 ¥4,000。
- 整局损失预算 ¥6,000，按各轮负盈亏的绝对值累计消耗，盈利不回补。
- 每次本金上限 = min(¥3,000，现金 − 剩余开支保护金，剩余损失预算)，按千元档位选择。预算不足 ¥1,000 时仍能等待。
- 每次结算都满足：现金 + 已付开支 = ¥20,000 + 累计模拟盈亏。
- FNV-1a 与整数混合生成稳定抽样；输入为实验编号、轮次和路径序号。相同输入产生相同结果，无网络随机源。
- 路径 A 是当轮实际抽中的模型结果；B–E 只是同一决定在同轮的额外独立抽样，不连接成完整财富轨迹。抽样有放回，可能重复；完整分支表始终可展开。
- 全部概率与情景由作者设定，不来自现实市场估计；未模拟税费、滑点、通胀、锁定期、长期持有。教学效果尚未验证。

## 文件

- `dist/index.html`：页面入口与内容安全策略。
- `dist/app.js`：开始、调查、先记录再揭晓、复盘、重玩、导出流程。
- `dist/engine.js`：纯函数账目、约束、随机抽样和确定性过程反馈。
- `dist/scenes.js`：五关剧情、证据和全部概率分支。

- `server.mjs`：无依赖本地静态服务器。
- `tests/engine.test.mjs`：核心规则测试。
- `tests/browser.mjs`：桌面/窄屏完整流程、键盘、重置、导出与隐私检查。
- `evidence/`：本机验证截图、浏览器结果与示例复盘；不上传站点。

## 验证

```sh
npm test

npm run test:browser
```

核心测试 10 项，包括 5,000 局、25,000 次决定的资金守恒和预算检查。浏览器测试 13 个检查点，覆盖桌面混合决策全流程、375px 触控尺寸全等待通关、320px 无横向溢出、键盘操作、重置、复盘、下载、笔记转义、无第三方请求、本地版无 Cookie/本地存储、无脚本异常。公开版单独检查托管安全 Cookie 与其他请求。

浏览器测试复用本 Mac 已安装的 `playwright-core` 和 Chromium，不会安装或下载软件。其他机器可通过 `PLAYWRIGHT_PATH` 指定 Playwright 模块入口绝对路径，`CHROMIUM_PATH` 指定浏览器可执行文件。`BASE_URL` 可改测试地址。公开托管的基础设施请求/日志需与应用自身无追踪行为区分。
