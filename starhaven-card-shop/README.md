# 星集卡牌店 · Starhaven v0.1

原创单机 3D 卡牌店经营试玩版。适用于 MacBook 上的现代 Safari / Chrome，也可用其他桌面浏览器运行。并非《TCG Card Shop Simulator》原版或授权移植。

## 在 MacBook 上开始（无需安装）

1. 解压 Starhaven-Mac.zip。
2. 双击 Starhaven.html；若被其他程序打开，右键 → 打开方式 → Safari 或 Google Chrome。
3. 点击「走进我的小店」，给余烬秘境「补满货架」，关闭面板，点击「开门营业」。

游戏的代码、3D 库与卡牌插图全部内置，打开后不需要联网，也不需要终端或 Python。在线版与离线版功能相同，各自独立保存进度。

## 操作

- W / A / S / D：前后左右移动。
- 按住触控板或鼠标并拖动：环顾；左右方向键：转向。
- E：与面前货架互动；也可点击底部管理按钮。
- V：切换俯瞰视角。
- 1 / 2 / 3 / 4：进货上架、开包、收藏册、升级店铺。
- Esc：关闭面板；店内按 Esc 打开帮助并暂停。
- 顾客选购、结账自动完成。打开管理面板或切换到其他浏览器标签页会暂停。

## 已实现

- 可走动的 3D 商店、货架、仓库、收银台、顾客路径、俯瞰视角。
- 采购、库存、补货、自定售价、价格影响购买概率。
- 约 4 分钟一个营业日、日结、经营费用。
- 3 个系列、12 幅原创伙伴插图、4 个稀有度，共 48 种收藏版本。
- 每包 5 张；普通/稀有/史诗/传说独立基础概率 65%/25%/8%/2%；整包至少稀有一张。
- 翻牌音效、稀有卡视觉效果、重复卡出售、收藏图鉴。
- 店铺等级、员工自动补货、推广、对战桌经营收入、成长目标。
- 自动存档、手动导出/导入、一次困难资金援助。
- 浏览器无法使用 WebGL 时，自动使用软件绘制兼容模式（画面更简化，性能可能较低）。

## 存档

自动存档属于当前浏览器和当前文件位置。移动/重命名离线文件、换浏览器、使用隐私浏览或清理网站数据，可能使原来的存档不可见。建议在帮助「?」中定期导出 JSON 存档。在线版和离线版可以互相导入存档。退出时暂停营业，重新进入后可继续同一天。

## 当前范围

这是可玩原型，没有联网、真实货币、完整的卡牌对战规则、原作全部内容或 Steam 集成。对战桌目前只有经营收益。尚未在实体 MacBook / Safari 上实机测试；已在受限 Chrome 浏览器的软件兼容模式中检查主要界面和交互，经营引擎另有自动化检查。
