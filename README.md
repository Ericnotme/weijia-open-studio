# Weijia Open Studio · 鲜唯佳的开放实验室

原创网页工具的清洁源码集合。当前发布 18 个独立项目，另有 2 个部分模块示例；其余源码仍在分批整理与上传，并非全部作品。

- weijia-lab：个人网站代码版，保留页面与互动；文章、照片、PDF、邮箱及艺术展内容已排除，视觉素材使用明确标记的 SVG 占位图。
- decision-lab-luck-and-judgment：决策模拟器
- healthspan-cn-research-hh：健康寿命研究界面
- investment-ruler：投资风险自检
- jianwei-ritual：见微
- jinniu-health-scenarios：健康情景模拟，未纳入来源未完成核对的地图边界
- life-alpha-cn-hh：Life Alpha
- life-meadow：人生原野

- neon-ante：霓虹底牌
- serendipity-search：偶然
- you-gong-ming：有共鸣
- meningioma-visit-prep：就诊准备代码与合成研究脚手架

- mama-care-compass：照护指南工具的清洁代码
- weijia-ai：个人 AI 工作台代码
- sibir-poker-lab：扑克研究实验室
- strategy-lab：策略研究工具
- starhaven-card-shop：星港卡牌店

- clock-lock：浏览器源码版，保留原 MIT 与第三方许可，不含 iOS 签名和生产配置

部分模块（并非完整产品）：
- china-opportunity-map-plain-modules：NextMove、即兴与音频逻辑，使用合成样例，不含原地图及数据
- signal-observatory-modules：研究、因子、周期计算逻辑，使用合成样例，不含数据库、业务内容及支付信息

每个目录含源码、LICENSE、EXPORT.md 与检查结果。MIT 只适用于原创软件代码；第三方许可保留，原文章、照片、PDF、个人数据不纳入授权。原生产网站、部署身份和 Git 历史不包含在内。请按每个 EXPORT.md 运行。

测试范围见各目录 EXPORT-VALIDATION.json。未做本次浏览器视觉验收；测试不代表临床、投资收益或真人学习效果验证。
